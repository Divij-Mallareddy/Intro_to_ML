# Assignment 1 — Machine Learning

## Source material

- `exercises-en-machine-learning-basics1.pdf` — official exercise sheet.
- `dataset.tsv` — dataset supplied for the text-annotation exercise.
- `main.typ` — shared Typst source for the group's written solutions.

## Exercises

The exercise sheet contains:
1. Machine Learning (general)
2. Specification of Learning Tasks
3. Data Annotation and Feature Engineering
4. Rule-Based Learning
5. Rule-Based Learning (Practice)
6. Rule-Based Learning in 2D

## Editing the shared solution

Edit `main.typ` in a coordinated way. Pull the latest `main` before starting and use a separate branch plus Pull Request for each contribution.

## Compile

From this directory:

```bash
typst compile main.typ main.pdf
```

Do not overwrite the supplied exercise-sheet PDF with the generated solution PDF. Keep the generated output named `main.pdf`.
